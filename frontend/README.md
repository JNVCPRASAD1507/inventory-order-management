# InventoryOS Frontend

React/Vite UI with Material UI, glassmorphism, gradient surfaces and Recharts.

The dashboard chart has a Daily / Weekly / Monthly menu. The selected menu changes the dataset rendered by Recharts.

Run:

```bash
npm install
npm run dev
```
